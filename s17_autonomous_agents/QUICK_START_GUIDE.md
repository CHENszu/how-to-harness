## 前置准备

在开始之前，请确保环境满足以下条件：

| 要求 | 说明 |
|------|------|
| **Python** | 版本 3.8+，推荐 3.10+ |
| **依赖包** | `pip install anthropic python-dotenv openai` |
| **环境变量** | 项目根目录需存在 `.env` 文件，包含 `ANTHROPIC_API_KEY` 和 `MODEL_ID` |
| **工作目录** | 确保在 `s17_autonomous_agents` 目录下运行 |

### 环境变量示例（.env）

```bash
ANTHROPIC_API_KEY=your_api_key_here
MODEL_ID=your_model_here
# 可选：自定义 API 地址
# ANTHROPIC_BASE_URL=https://api.deepseek.com/v1
```

### 启动程序

```bash
python code_annotated.py
```

启动成功后，你会看到以下提示：

```
s17: Autonomous Agents — 自己看板，自己认领 (中文版)
试着输入：'创建 3 个互相独立的任务，然后召唤两个队友 alice 和 bob。看着他们自己认领任务干活。'

s17 >>
```

这时你已经进入交互式命令行界面，可以开始指挥你的自主代理团队了。

## 如何创建任务

### 方式一：直接输入指令（推荐）

在交互式命令行中，直接告诉主代理（Lead Agent）你想创建什么任务。例如：

```text
s17 >> 请创建 2 个任务：第一个是"编写README文档"，第二个是"修复登录Bug"
```

主代理会通过调用 `create_task` 工具在任务看板（`.tasks/` 目录）中创建任务文件。

### 方式二：指定依赖关系

当任务之间存在依赖时，可以用 `blockedBy` 字段指定前置任务：

```text
s17 >> 创建任务A"编写API接口"，然后创建任务B"编写接口文档"，任务B依赖于任务A
```

代理会自动为任务 B 设置 `blockedBy: [task_A_id]`，**任务 B 只有在任务 A 完成后才能被认领**。

### 任务状态说明

每个任务有 4 种状态：

| 状态 | 含义 |
|------|------|
| `pending` | 待认领，正在等待代理抢单 |
| `in_progress` | 已认领，正在进行中 |
| `completed` | 已完成 |
| （可扩展）| 通过 `blockedBy` 表示依赖关系 |

## 如何召唤队友代理

### 基本召唤

召唤队友的核心指令是 `spawn_teammate`，通常这样使用：

```text
s17 >> 召唤两个队友 alice 和 bob 来帮忙干活
```

主代理会调用 `spawn_teammate` 工具，在后台启动两个独立线程：

```
[teammate] alice spawned as 助手 (autonomous)
[teammate] bob spawned as 助手 (autonomous)
```

### 队友代理的三大生命周期

召唤成功后，每个队友代理会自动进入以下生命周期循环：

```
┌─────────┐    完成任务     ┌─────────┐    发现新任务     ┌─────────┐
│  WORK   │ ───────────────> │  IDLE   │ ───────────────> │  WORK   │
│ （干活） │ <─────────────── │（轮询） │ <─────────────── │（干活） │
└─────────┘   发现新任务     └─────────┘                  └─────────┘
      │                              │
      └────────────（超时60秒）──────┘
                    │
              ┌─────▼─────┐
              │ SHUTDOWN   │
              │ （下班退出）│
              └────────────┘
```

| 阶段 | 行为 |
|------|------|
| **WORK** | 调用工具干活，最多思考 10 轮 |
| **IDLE** | 干完活后不退出，每 5 秒轮询一次邮箱和任务看板 |
| **SHUTDOWN** | 连续 60 秒无新任务，或被老大关机后，自动总结退出 |

### 关键行为

- **自动抢单**：队友在 IDLE 阶段扫描看板，发现 `pending` 且 `blockedBy` 全完成的任务，会自动调用 `claim_task` 认领。
- **防重复**：任务有 `owner` 字段，已被认领的任务不会被重复抢占。
- **自主退出**：所有任务完成后，队友轮询 60 秒仍无新活，自动下班：

```
[Team] 队友 alice 体面退出
```

## 如何监督任务进度

### 查看所有任务

告诉主代理查看任务看板：

```text
s17 >> 帮我看看现在有哪些任务
```

主代理会调用 `list_tasks` 工具，返回任务列表，包含任务 ID、主题和状态。

### 查看单个任务详情

```text
s17 >> 查看任务 task_xxxx 的详细内容
```

主代理调用 `get_task` 获取完整 JSON，包括描述和依赖关系。

### 发送消息给指定队友

```text
s17 >> 给 alice 发消息，让她加快进度
```

主代理调用 `send_message` 工具将消息投递到 alice 的邮箱（`.mailboxes/alice.jsonl`）。

### 请求队友关机

```text
s17 >> 让 bob 下班
```

主代理调用 `request_shutdown` 工具发送关机协议消息。队友收到后走**优雅关闭**流程：
1. 发送 `shutdown_response` 确认
2. 总结当前工作
3. 发送结果给主代理
4. 退出线程

### 全局进度观察

主代理会实时打印团队动态，你可以通过以下终端日志判断团队健康状况：

| 日志示例 | 含义 |
|---------|------|
| `[create] 编写README文档` | 任务已创建 |
| `[Team] 召唤队友 alice 成功` | 队友已上线 |
| `[idle] alice auto-claimed: 编写README文档` | 队友自动认领任务 |
| `[complete] 修复登录Bug ✓` | 任务已完成 |
| `[Team] 队友 bob 体面退出` | 队友正常下班 |
| `[Team] 所有队友均已完成工作并退场` | 全队收工 |

### 一键体验完整流程

在 `s17 >>` 提示符后直接输入以下指令，即可体验自动化的完整协作流程：

```text
请创建 3 个互相独立的任务，然后召唤两个队友 alice 和 bob。接下来你什么都不用做，就看着他们自己认领任务干活。
```

之后你会看到：老大创建任务 → 召唤队友 → 队友自动抢单 → 并行干活 → 自动完成 → 超时下班，全程无需人工干预。

## 常见问题与排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 启动报 `ModuleNotFoundError` | 未安装依赖 | 运行 `pip install anthropic python-dotenv openai` |
| 报 `KeyError: MODEL_ID` | `.env` 缺少配置 | 在 `.env` 中补上 `MODEL_ID` |
| 队友一直不认领任务 | 任务有 `blockedBy` 依赖未完成 | 先完成前置任务，或创建无依赖的任务 |
| 队友已退出但任务未完成 | 任务被标记为 `in_progress` 但未 complete | 手动调用 `complete_task` 或重新召唤队友 |
| 任务名重复冲突 | 同名的队友只能存在一个 | 换一个队友名字，如 alice_2 |

## 总结

自主学习代理的核心思想是**智能自组织**：

- **老大**只负责创建任务，不需要手动分配。
- **队友**自己看板、自己认领、自己干活、自己下班。
- 整个团队通过 **任务看板** 与 **消息邮箱** 两个基础组件协同工作。

现在你已掌握了创建任务、召唤队友和监督进度三大核心操作，快去体验「全自动敏捷开发团队」吧！🎉

## 🎯 核心思考与通俗理解

如果你一路学到了这里，你会发现前 19 节就像是在**收集无限宝石**：
- **S01-S02**：大模型的嘴巴和手（Agent Loop 和 Tool Use）。
- **S04**：安检门（Hooks 拦截器）。
- **S08, S09, S11**：大脑保养术（Context 压缩、记忆提取、错误恢复）。
- **S13-S14**：后台洗碗机和闹钟（Background Tasks 和 Cron 定时任务）。
- **S15-S17**：摇人系统（子 Agent 和团队协议）。
- **S18-S19**：物理隔离板和万能转换插头（Worktree 和 MCP）。

在之前的教学中，为了不让你晕车，我们每学一个新机制，就单独写一个小 Demo。但真实的工业级 Agent 绝不是散装的，它们必须同时在一个大脑（主循环）的调度下协同工作。

**S20 节本质上就是一艘“超级航母”的下水仪式。**
所有的功能模块不再是独立的试验品，而是被精细地编排进了同一个 `agent_loop`。

### 直观比喻：航母指挥中心的一轮调度

在这个“终极循环”中，Agent 每转一圈，其实是在指挥中心走了一遍标准化流程：
1. **看闹钟**：先看看有没有到点必须做的事（`consume_cron_queue`）。
2. **看邮箱**：看看后台洗碗机洗完了没，或者小弟有没有发来报告（`inject_background_notifications`）。
3. **查备忘录**：要是连着干了几波活都没写备忘，系统就会吼它一句“更新你的 Todos！”。
4. **组装工具**：把本地工具和通过 MCP 外接的工具打包到一起（`assemble_tool_pool`）。
5. **召唤大脑**：把当前所有的上下文、记忆、工具塞给大模型（调用 DeepSeek/OpenAI）。
6. **处理超载**：如果大模型抱怨“信息太多我装不下了”（Finish Reason: length），马上启动记忆压缩机（`reactive_compact`）。
7. **执行动作**：大模型决定用什么工具，通过“安检门”（Hooks）后执行，并将结果塞回上下文。

## 🛠️ 深度改造记录 (DeepSeek 适配版)

为了让这个包含 **27 个工具**、长达 **2800 多行**的终极代码在你的 Windows 电脑上通过 DeepSeek API 顺畅运行，我们做了一次“外科手术级”的重构：

### 1. 异构模型数据结构的统一骗局 (`MockBlock`)
原教程是针对 Anthropic 写的，它的工具调用对象结构是 `block.name` 和 `block.input`。而 OpenAI (DeepSeek) 返回的是 `tool_call.function.name` 和 JSON 字符串格式的 `arguments`。
因为这套系统里 Hooks（安检门）极度依赖旧的数据结构，为了不把所有安检门拆了重造，我引入了一个 `MockBlock` 类。它就像一个**伪装面具**，把 OpenAI 的 `tool_call` 穿上 Anthropic 的衣服，再送进安检门，完美实现了底层无缝替换。

### 2. 工具池大换血 (AST 重写)
这可能是改造中最麻烦的一步。S20 包含了史上最庞大的工具集（内置了 19 个，小弟专属 5 个，MCP 插件若干）。Anthropic 格式用的是 `input_schema`，而 OpenAI 需要 `parameters` 以及外层的 `{"type": "function", "function": {...}}` 嵌套。
我们没有手动去改那几百行 JSON，而是利用 Python 的 `ast`（抽象语法树）模块，写了一个脚本在内存里解析了代码，精准地将所有工具重塑成了标准的 OpenAI 函数调用格式。

### 3. “字数超载”信号的转译
在极长的会话中，上下文经常爆满。Anthropic 会返回 `stop_reason == "max_tokens"`，而 OpenAI 会返回 `finish_reason == "length"`。我在核心主循环中精准捕捉了这个差异，确保在上下文撑爆时，Agent 依然能冷静地扩大 Token 限制或启动压缩（Compact），而不是直接崩溃。

## 🚀 运行与验证

在运行 S20 之前，请确保你已经通过 `S19` 或其他途径在系统里注册了 MCP 工具，或者就在这里测试最基础的自主接单功能。

```bash
# 请确保当前位于 how-to-harness 目录下，并激活了 harness 环境
conda activate harness
python s20_comprehensive/code_annotated.py
```

### 体验建议：
1. **测试全局工具池**：输入 `帮我看看你现在有多少工具可用`，感受一下这艘“航母”的火力。
2. **测试任务大串联**：输入 `帮我建一个叫 s21_test 的 task，然后在里面写一个 python 脚本打印 hello world，并且开启子 agent 去完成`。看看它如何行云流水地调用 Todo -> Task -> File 等一系列工具。

# 第7课：长期记忆与启发式检索 (Long-term Memory & Heuristic Retrieval)

在前一节中，我们解决了 Agent 在**单个长对话**中脑容量（Token）被撑爆的问题，实现了**短期记忆（会话内存）**。

但是，短期记忆有一个致命缺点：一旦你关掉终端，或者开启一个新的会话，Agent 就会把你教它的东西忘得一干二净。它不记得你的代码规范，不记得你刚才解决的疑难 Bug，也不记得你的个人偏好。

为了解决这个问题，OpenHarness 实现了一套基于本地文件和启发式搜索的**长期记忆系统 (Durable Memory)**。

## 💡 核心隐喻：文件柜与检索员

继续我们前一节的比喻：
*   **短期记忆（办公桌与便签纸）**：负责单个任务的执行，任务结束后桌子会被清空。
*   **长期记忆（文件柜）**：位于你办公桌旁边的一个巨大文件柜。当你总结出一条有价值的经验时（比如“这个项目必须用 UTF-8 编码”），你会主动把它写成一份带有**标签（Frontmatter）**的文档，锁进文件柜里。
*   **启发式检索（检索员）**：当你接手一个新任务时（即用户输入新 Query），你不必把文件柜里所有的文件都堆在桌子上（那样又会 Prompt too long）。你只需要让“检索员”根据任务关键词去文件柜里翻找。那些**标题命中**、**内容相关**、**标记为高重要性**的文件，会被优先挑出来，放在你今天的“办公桌”上作为背景参考。

## 🛠️ 本节重点代码结构

我们直接在 06 节的基础上，引入 `memory.py` 和一个新的工具：

1. **`memory.py`**:
   - `save_memory()`: 将知识以 Markdown 文件（带 YAML Frontmatter 风格头）的形式保存到本地 `.memory` 隐藏目录中。
   - `search_memory()`: 模拟 OpenHarness 的**启发式打分机制**（元数据命中高权重 + 正文命中 + 重要性加分），检索最相关的 Top K 条记忆。
2. **`tools.py`**: 新增 `SaveMemoryTool` 工具，赋予大模型主动记录知识的能力。
3. **`engine.py`**: 在 Agent Loop 开始前，先拿用户的输入去 `search_memory()`，把检索到的长期记忆直接注入到系统的 Prompt 中。

## 🚀 运行与测试

```bash
python main.py
```

**测试流程**：
1. 先告诉它一个偏好：*“记住：以后在写 Python 代码时，必须加上中文注释，这对我非常重要！”* （它会自动调用 `save_memory` 工具记录下来）。
2. 按 `q` 退出程序（模拟会话结束，短期记忆清空）。
3. 重新运行 `python main.py`，然后问它：*“给我写一个冒泡排序。”*
4. 观察它是否能自动检索出之前的偏好记忆，并按照带有中文注释的规范输出代码！
